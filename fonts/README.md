# Built-in fonts

rOsmo360's text overlays come with these fonts, built into the program. Each
keeps its own licence, in its folder here and beside the program in every
release.

| Font | Licence | From |
|---|---|---|
| Inter | SIL Open Font License 1.1 | github.com/google/fonts `ofl/inter` |
| Montserrat | SIL Open Font License 1.1 | github.com/google/fonts `ofl/montserrat` |
| Bebas Neue | SIL Open Font License 1.1 | github.com/google/fonts `ofl/bebasneue` |
| Playfair Display | SIL Open Font License 1.1 (Reserved Font Name "Playfair Display") | github.com/google/fonts `ofl/playfairdisplay` |
| Caveat | SIL Open Font License 1.1 | github.com/google/fonts `ofl/caveat` |
| Permanent Marker | Apache License 2.0 | github.com/google/fonts `apache/permanentmarker` |

Inter, Montserrat and Caveat are static Regular and Bold instances made with
fontTools from Google Fonts' variable fonts (Inter at its display optical
size, 32). Their licences reserve no font names. Playfair Display's licence
reserves its name, so its variable font is included unmodified. Bebas Neue
and Permanent Marker are the files as published.
